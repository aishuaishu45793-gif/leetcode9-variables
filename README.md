# 🐍 Print Hello World

This is my first Python practice program as part of my **LeetCode and Python learning journey**.

## 🧩 Problem

Write a Python program that prints:

```text
Hello World
```

## 💻 Python Code

```python
print("Hello World")
```

## 📤 Output

```text
Hello World
```

## 🔍 Explanation

The `print()` function is used to display text or values on the screen.

In this program:

```python
print("Hello World")
```

* `print()` → Python's built-in function for displaying output.
* `"Hello World"` → The text that we want to display.
* The text is written inside quotation marks because it is a **string**.
